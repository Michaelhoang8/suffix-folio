Reading the model

Suffixes are sorted by numeric Unicode code point, without locale collation or normalization. Prefix doubling builds the index; Kasai's algorithm computes adjacent longest common prefixes. The sum of suffix lengths minus LCP lengths counts distinct nonempty substrings.

Up to 12,000 text code points and 256 query code points. Empty text is valid; an empty query is rejected. Construction runs in a worker. This is an in-memory teaching index, without fuzzy search, stemming, incremental updates, or a persistent document database.
